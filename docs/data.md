## 数据说明

### camp_data.js

- **__CAMP_CLASS**：羁绊分类
- **__CAMP_MEM**：各羁绊的成员列表
- **__CAMP_NUM**：各羁绊每层激活所需角色数量
- **__CAMP_COLORS**：各羁绊每层激活后的高亮颜色
- **__CAMP_STATS**：羁绊内容

### chr_data.js

- **__CHR_EXPERTS**：专家顾问角色列表
- **__CHR_SPEND**：角色费用分组
- **__CHR_POSITION**：角色站位分组
- **__CHR_INTRO**：角色介绍文本

### equipments_data.js

- **__EQUIPMENTS**：装备分组
- **__LIMITS**：装备激活条件
- **__MERGE**：装备合成配方
- **__STATS**：装备基础属性

### environment_data.js

- **window.__ENVIRONMENT_DATA**：环境祝福数据

### strategy_data.js

- **window.__STRATEGY_DATA**：投资策略数据

### enemy_data.js

- **window.__ENEMY_LABEL**：敌方词缀数据
- **window.__ENEMY_GROUP**：敌方势力编队数据

### update_data.js

- **window.__UPDATE_DATA**：版本更新数据
- **window.__UPGRADE_DATA**：赛季扩充数据
- **window.__FIX_DATA**：问题修复数据
